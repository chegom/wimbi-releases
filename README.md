# Wimbi Releases

This repository is the public download channel for Wimbi, an AI work browser
for Korean small businesses. Application source code is maintained privately;
this repository contains release notes, signed installers, update artifacts,
and checksums only.

## Download safety

Only download files attached to a GitHub Release in this repository. A
production release must include signed installers and `SHA256SUMS.txt`.

Expected assets:

- `Wimbi-mac-arm64.dmg`
- `Wimbi-mac-x64.dmg`
- `Wimbi-mac-arm64.zip`
- `Wimbi-mac-x64.zip`
- `Wimbi-windows-x64.exe`
- `latest-mac.yml`
- `latest.yml`
- `SHA256SUMS.txt`

No installer is published until platform installation, signature, and update
checks are complete. If the Releases page is empty, the production download is
not available yet.

Official website: <https://wimbi-browser.pages.dev/>
